# J.A.R.V.Y. Roadmap

## Portfolio strategy

J.A.R.V.Y. is the flagship project. Smaller portfolio repositories will later demonstrate the individual engineering skills used here: frontend, backend, databases, APIs, RAG, computer vision, agents, testing, and deployment.

## Definition of done

A milestone is not complete because the feature appears to work once. A feature is considered portfolio-ready when it has a clear interface, error handling, documentation, and an appropriate level of automated testing.
